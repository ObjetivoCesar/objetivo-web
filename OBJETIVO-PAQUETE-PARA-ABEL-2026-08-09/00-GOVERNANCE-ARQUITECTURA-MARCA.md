# Governance — Arquitectura de Marca y Productos

> **Para qué sirve:** Definir QUÉ es OBJETIVO (marca personal), QUÉ es ActivaQR (empresa hermana), y DÓNDE vive cada producto/servicio. Sin esta decisión, el CRM no puede clasificar leads ni el sitio puede tener un copy coherente.
> **Estado:** ✅ APROBADO POR CÉSAR — Opción C con ajustes.
> **Fecha aprobación:** 2026-08-09
> **Origen:** Hallazgo durante auditoría SEO + Manual de Marca Personal v1.3.

---

## ✅ DECISIONES TOMADAS POR CÉSAR

### Decisión 1 — Arquitectura: **OPCIÓN C (Híbrido)**
**Razón de César:** "Me gusta la idea de la 'C' porque entre los sitios me puedo transferir autoridad."

**Regla aplicada:**
- Productos con modelo recurrente/suscripción → ActivaQR
- Productos puntuales con ticket alto que requieren voz de César → OBJETIVO
- **Transferencia de autoridad entre sitios es VÁLIDA y deseada** (no canibalización)

### Decisión 2 — CRM: Etiquetar todos los leads
**Regla:** Todos los leads se etiquetan en el CRM con `empresa_origen` y se atienden:
- **Con Ale** → si ticket <$1,000 (autónomo) o si César delega explícitamente
- **Directo con César** → si ticket ≥$1,000 (según Regla #10 Bitácora)

### Decisión 3 — Facturación: Servicio profesional unificado
**Regla:** Todo se factura bajo el servicio profesional de César como se hace actualmente.
- A futuro: facturación separada por empresa si crece el volumen
- NO bloqueante ahora

### Decisión 4 — ELIMINAR Tarjeta Digital Simple y Profesional de OBJETIVO
**Razón:** Canibalización directa con ActivaQR (mismo producto, pricing distinto).
**Acción:**
- Eliminar SKUs #11 y #12 de OBJETIVO
- Crear redirección 301 a ActivaQR
- "Limpiemos de cosas baratas, cortamos el tráfico con una redirección"

### Decisión 5 — Software a Medida NO es ActivaQR
**Confirmación:** Software a Medida es OBJETIVO puro. Se refiere a construir software según lo que el cliente quiera (CRM, automatización, fruto de reingeniería, etc.).
**NO es producto ActivaQR.** Es servicio consultivo de César.

## 🔍 Evidencia del problema actual

**Lo que el sitio cesarreyesjaramillo.com hace MAL:**
- Tiene categorías de blog llamadas `ActivaQR Gastronomía`, `ActivaQR Networking` y `Software Personalizado`
- Tiene landings (`/menu-digital`, `/motor-reservas-hotel`, `/software-gestion-servicios`, `/mensajeria`) que venden productos que también existen en activaqr.com
- Tiene una sub-página `/servicios/desarrollo-web/tarjeta-digital` ($60 única) que ES COMPETENCIA DIRECTA con el plan "Contacto Digital" de ActivaQR ($35/año)

**Lo que el Manual de Marca v1.3 dice (Cap 0.6):**
> *"Otros negocios o productos de César —como ActivaQR o el sistema SaaS de cobranzas (empresa hermana, desarrollado con Christopher y Abel)— se manejan por separado, con su propia estrategia comercial y de ventas. Pueden tomar prestadas técnicas de este manual (por ejemplo, el reframe de producto a resultado, 1.6), pero no se integran como avatares ni como contenido dentro de este sistema."*

**Conclusión:** El Manual es claro — ActivaQR es empresa hermana. Pero el sitio OBJETIVO está vendiendo productos de ActivaQR como si fueran propios.

**Regla:** OBJETIVO vende TODO. ActivaQR se posiciona como submarca técnica para productos recurrentes. Mismo dominio, secciones separadas.

**Distribución de SKUs:**

| Producto / Servicio | Dónde vive | Razón |
|---|---|---|
| Todos los servicios consultivos | OBJETIVO (cesarreyesjaramillo.com/servicios/...) | Servicios de César |
| Tarjeta Digital Simple | OBJETIVO o ActivaQR | Co-existencia, pricing distinto |

**Ventajas:**
- ✅ Mantiene el catálogo completo en un solo lugar

**Desventajas:**
- ❌ Viola el Manual v1.3 Cap 0.6
- ❌ ActivaQR pierde identidad propia
- ❌ El footer "BUILT BY CÉSAR REYES JARAMILLO" sugiere separación que no se aplica
- ❌ Dos URLs para productos similares (activaqr.com vs cesarreyesjaramillo.com) sin lógica clara

---

### Opción C — Híbrido: cada producto en su mejor hogar

**Regla:** Decisión por producto. Algunos viven en OBJETIVO, otros en ActivaQR, según la naturaleza del producto y la estrategia comercial.

**Criterios de decisión:**
1. **¿Es recurrente?** (suscripción anual/mensual) → ActivaQR
2. **¿Es puntual?** (pago único) → OBJETIVO
3. **¿Es para un nicho muy específico?** (restaurantes, hoteles) → ActivaQR (producto independiente)
4. **¿Es un servicio donde César entrega personalmente?** → OBJETIVO
5. **¿Tiene sistema automatizado de entrega?** → ActivaQR

**Distribución sugerida (mi propuesta):**

| Producto / Servicio | Dónde vive | Cumple criterio |
|---|---|---|
| Análisis Estratégico (todos los 6) | OBJETIVO | 4 ✓ |
| Plan SEO + Alianza | OBJETIVO | 4 ✓ |
| Auditoría SEO + Rediseño | OBJETIVO | 4 ✓ |
| Web (Estática, Pro, Plataforma) | OBJETIVO | 2 ✓ |
| E-commerce | OBJETIVO | 4 ✓ |
| Software a Medida (4 módulos) | OBJETIVO | 4 ✓ |
| Tarjeta Digital Simple (entrada) | **ActivaQR** | 1 ✓ (también 2 ✓) |
| MenúObjetivo (4 planes) | **ActivaQR** | 1, 3 ✓ |
| HotelObjetivo (3 planes) | **ActivaQR** | 1, 3 ✓ |
| Mensajería Objetivo | **ActivaQR** | 1, 5 ✓ |

**Ventajas:**
- ✅ Respeta la naturaleza de cada producto
- ✅ Coherente con Manual v1.3 Cap 0.6
- ✅ ActivaQR se especializa en SaaS recurrentes y productos automatizados
- ✅ OBJETIVO se especializa en servicios consultivos y a medida

**Desventajas:**
- ❌ El cliente que quiere TODO tiene que ir a dos sitios
- ❌ Requiere trabajo de redirección y cross-linking

## 🚦 Recomendación del agente

**Opción C (híbrido)** es la más coherente porque:

1. **Respeta el Manual v1.3** — ActivaQR se mantiene como empresa separada con su propia estrategia
2. **Resuelve el conflicto de pricing** — ActivaQR vende planes anuales, OBJETIVO vende servicios puntuales
3. **Permite cross-sell natural** — Cliente compra Análisis de Competencia en OBJETIVO → derivar a MenúObjetivo en ActivaQR para su restaurante
4. **El CRM puede tener UN solo pipeline** pero con campo `empresa_origen` (`objetivo` / `activaqr` / `cross`)
5. **El blog puede tener categorías por marca** sin contradicción

- Cuando un cliente ActivaQR tiene +6 meses y quiere escalar (captar clientes)

Como agente con "rol de abogado del diablo", **mi recomendación firme es Opción C** porque:
