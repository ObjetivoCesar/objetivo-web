## Descripción comercial

**Primera Web Estática** — La primera web real para un negocio que está dando el salto digital.

(Inferencia basada en la escalera de precios — sigue el patrón "más funcionalidades por más precio".)

### Diferencias vs Tarjeta Digital Profesional ($150)
- Sitio web completo (no solo una página de contacto)
- Múltiples secciones (home, sobre nosotros, servicios, contacto)
- Hosting y dominio completo incluido

## Proceso operativo (inferido)

**Framework de 4 semanas (de la landing):**
- Semana 1: Descubrimiento — entender el negocio
- Semana 2: Desarrollo — implementación
- Semana 3: Revisión — feedback del cliente
- Semana 4: Lanzamiento — publicación

**Cliente entrega:**
- Contenido textual básico (o se redacta con IA)
- Logo y material gráfico
- Información del negocio
- Preferencias de estilo

**César entrega (4 semanas):**
- Web estática funcional en dominio propio
- Hosting configurado
- Tutorial de autogestión básico
- Sin mantenimiento posterior (o paquete adicional)
